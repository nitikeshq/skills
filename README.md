# skills

This repository contains Qwegle skills for one-agent software delivery.

The global operating model is spec-driven development:

1. Understand the goal and constraints.
2. Write observable requirements using EARS-style statements.
3. Design the solution and record tradeoffs.
4. Break the design into actionable tasks.
5. Implement task by task.
6. Validate with tests, checks, and review.
7. Keep the PR engaged until review feedback is handled.

Core process areas:

- Methodology: spec-driven development from intent to delivery.
- Process guide: requirements, design, tasks, workflow diagrams, and decision points.
- AI reasoning: scope, risk, ownership, evidence, and validation checkpoints.
- Prompting strategies: reusable collaboration templates and best practices.
- Execution guide: implementation, quality assurance, and troubleshooting.
- Resources: standards, tools, and references.
- Examples: simple features, complex systems, case studies, and pitfalls.
- Templates: requirements, design, and task planning formats.

The intended behavior is that one agent can own the full flow: clarify, specify, design, implement, test, review, update the PR, and report the outcome.
